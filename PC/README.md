# SCARA 三关节运动学仿真器

这是一个纯 Python + PyQt5 的交互式仿真程序，模型为：

- 大臂 `L1 = 250 mm`
- 小臂 `L2 = 150 mm`
- 旋转舵机到夹爪工作点 `L3 = 100 mm`
- 三个关节均在 XOY 平面旋转
- 升降轴范围暂设为 `Z = 0~120 mm`

## 电机角与数学角约定

运动学内部统一使用“逆时针为正”的相对数学角，发送给执行器前再转换为机械角：

- 大臂 `M1`：从 X 轴正方向开始，顺时针为正，范围 `0~350°`；`q1 = -M1`。
- 小臂 `M2`：相对大臂的关节角，逆时针为正，范围 `28.5~300°`。初始 `M2=28.5°` 表示向 Y 轴负方向内折，内部数学相对角为 `q2=M2-180°=-151.5°`。
- 夹爪旋转舵机：相对小臂旋转，顺时针为正。舵机 `127°` 时与小臂平行，范围 `0~270°`；内部数学相对角为 `q3=127°-舵机角`，对应 `+127~−143°`。

因此三个连杆的全局方向依次为 `q1`、`q1+q2`、`q1+q2+q3`，每个后级关节都相对上一级末端计算。

程序启动或点击“复位姿态”后，默认显示机械零点：`M1=0°`、`M2=28.5°`、`舵机=127°`、`Z=0 mm`，而不是自动运行示例坐标。

程序可以输入 `(X, Y, Z, φ)`，完成逆运动学解算、关节限幅判断和动画运动；也可以直接点击左侧工作区指定 X、Y。红色目标表示坐标或关节角超限。

界面采用响应式布局，启动时会根据屏幕可用尺寸自动调整窗口，已针对 `1024×600` 显示屏压缩布局。改变窗口大小时机械臂画布会自动缩放；高度不足时右侧控制面板可滚动。

## Windows 本地运行

```powershell
cd P:\LoongSonProject\2K1000LA\PC
python scara_simulator.py
```

依赖只有 PyQt5：

```powershell
pip install PyQt5
```

## 龙芯板运行

龙芯现有环境若已经能够 `import PyQt5`，复制本目录后直接运行：

```bash
cd ~/2K1000LA/PC
python3 scara_simulator.py
```

如果桌面使用 Wayland 而 Qt 没有自动选择显示后端，可尝试：

```bash
QT_QPA_PLATFORM=wayland python3 scara_simulator.py
```

若 Wayland 插件不可用，则使用：

```bash
QT_QPA_PLATFORM=xcb python3 scara_simulator.py
```

## 自检

```bash
python3 -m unittest -v test_kinematics.py
```
