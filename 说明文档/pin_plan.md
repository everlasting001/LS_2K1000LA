# 四轴 SCARA 最终引脚与连接规划

> FPGA：GW5AT-LV60PG484AC1/I0；控制中枢：龙芯2K1000LA；无线执行端：三块 ESP32-S3-R8N8。

## 1. 最终拓扑

```text
龙芯2K1000LA
    │ I2C-1，FPGA从机地址0x20
    ▼
GW5AT-60K FPGA（校验、限幅状态、UART转发）
    │ UART 115200 8N1 + CRC-8
    ▼
底盘S3（路由 + 大臂M1）
    ├── ESP-NOW + CRC-8 ──► 上臂S3（升降M2 + 小臂M3 + 两舵机）
    └── ESP-NOW + CRC-8 ──► 传送带S3（传送带M4 + 四路电磁铁）
```

最终方案没有 C3。四路电磁铁也不再连接 FPGA，FPGA J14的21～24脚恢复为空闲。

## 2. FPGA 与龙芯

| 功能 | FPGA管脚 | 方向/说明 |
|---|---|---|
| 50MHz时钟 | F13 | 输入 |
| 复位 | D1 | 低有效 |
| I2C_SCL | D20 | 龙芯 I2C-1，3.3V，上拉 |
| I2C_SDA | C22 | 龙芯 I2C-1，3.3V，上拉 |
| 蜂鸣器 | A13 | 输出 |
| 调试串口 TX | T18 / J14-20 | 输出到 USB-TTL RX |

## 3. FPGA 与底盘 S3

| 信号 | FPGA本端 | 通信对方 | 完整连接 |
|---|---|---|---|
| `router_txd` | P19 / J14-30，TX输出 | 底盘S3 GPIO20 RX | FPGA P19 TX → 底盘S3 GPIO20 RX |
| `router_rxd` | A15 / J14-29，RX输入 | 底盘S3 GPIO21 TX | FPGA A15 RX ← 底盘S3 GPIO21 TX |
| GND | GND | GND | 必须共地 |

双方均为3.3V逻辑。不要使用5V TTL电平。

## 4. 三块 S3 接线

### 4.1 底盘 S3

MAC：`44:1B:F6:83:E0:80`

| 底盘S3本端 | 通信对方 | 完整连接 |
|---|---|---|
| GPIO1 TX | 大臂M1 RX | S3 GPIO1 TX → M1 RX |
| GPIO2 RX | 大臂M1 TX | S3 GPIO2 RX ← M1 TX |
| GPIO20 RX | FPGA P19 TX / router_txd | S3 GPIO20 RX ← FPGA P19 TX |
| GPIO21 TX | FPGA A15 RX / router_rxd | S3 GPIO21 TX → FPGA A15 RX |

### 4.2 上臂 S3

MAC：`44:1B:F6:81:C4:E0`

| 上臂S3本端 | 通信对方 | 完整连接 |
|---|---|---|
| GPIO17 TX | 升降M2 RX | S3 GPIO17 TX → M2 RX |
| GPIO18 RX | 升降M2 TX | S3 GPIO18 RX ← M2 TX |
| GPIO15 TX | 小臂M3 RX | S3 GPIO15 TX → M3 RX |
| GPIO16 RX | 小臂M3 TX | S3 GPIO16 RX ← M3 TX |
| 4 | 旋转舵机信号，0～270°，复位127° |
| 5 | 夹爪舵机信号，0～180° |

舵机使用独立5V电源，电源地与S3共地；舵机电源不可直接取自S3的3.3V引脚。

### 4.3 传送带 S3

MAC：`44:1B:F6:83:DF:D8`

| 传送带S3本端 | 通信对方 | 完整连接 |
|---|---|---|
| GPIO17 TX | 传送带M4 RX | S3 GPIO17 TX → M4 RX |
| GPIO18 RX | 传送带M4 TX | S3 GPIO18 RX ← M4 TX |
| 7 | 电磁铁1驱动板逻辑输入 |
| 8 | 电磁铁2驱动板逻辑输入 |
| 9 | 电磁铁3驱动板逻辑输入 |
| 10 | 电磁铁4驱动板逻辑输入 |

电磁铁为高电平推出。GPIO只连接MOS/继电器驱动板的逻辑输入，不能直接连接线圈。线圈使用独立电源，驱动板与S3共地。

## 5. Emm 电机串口

| 电机 | 控制板 | S3串口 | TX/RX | Emm地址 |
|---|---|---|---|---:|
| M1 大臂 | 底盘S3 | Serial1 | 1/2 | 1 |
| M2 升降 | 上臂S3 | Serial1 | 17/18 | 1 |
| M3 小臂 | 上臂S3 | Serial2 | 15/16 | 1 |
| M4 传送带 | 传送带S3 | Serial1 | 17/18 | 1 |

每台电机独占一条UART，所以全部保留Emm默认地址1，不会发生地址冲突。串口参数统一为 `115200 8N1`，所有控制板和电机信号地必须共地。

## 6. 电磁铁保护

- 上电、复位、急停和底盘通信超时：GPIO7～10全部输出LOW。
- 命令必须为one-hot，同一时间最多一路推出。
- 默认推出200ms，默认冷却500ms。
- 固件将单次连续推出限制在最大2000ms。
- FPGA只发送目标、持续时间和冷却时间，不再直接驱动线圈。

## 7. FPGA UART协议

### FPGA → 底盘S3：13字节

```text
AA flags value1_LE32 value2_LE32 speed_LE16 CRC8
```

| flags | 含义 |
|---:|---|
| bit1 | M2升降 |
| bit2 | M3小臂 |
| bit3 | 两个舵机 |
| bit4 | 全系统急停 |
| bit5 | M1大臂 |
| bit6 | M4传送带 |
| bit7 | 四路电磁铁 |

CRC采用CRC-8，多项式 `0x07`、初值 `0x00`。

`value1`和`value2`均为有符号32位脉冲数，范围为 `-2147483648～2147483647`。例如传送带1米约需48500脉冲，升降120mm约需192000脉冲，均可直接发送，不再拆包或发生16位溢出。

### 底盘S3 → FPGA：17字节

```text
AA flags M2pos(2) M3pos(2) M1pos(2) M4pos(2)
SV1(2) SV2(2) EM_state error CRC8
```

多字节字段均为小端序。UART校验失败时整帧丢弃；ESP-NOW段另外对命令包和状态包执行CRC-8校验。

## 8. FPGA I2C寄存器

| 地址 | 方向 | 内容 |
|---:|---|---|
| 0x00 | W | CMD：bit7上臂、bit6底盘、bit3舵机、bit1急停、bit0电磁铁 |
| 0x01～0x02 | W | 旧版M2低16位兼容入口，自动符号扩展 |
| 0x03～0x04 | W | 旧版M3低16位兼容入口，自动符号扩展 |
| 0x05～0x06 | W | 电机速度 |
| 0x08～0x09 | W | 旧版M1低16位兼容入口，自动符号扩展 |
| 0x0A～0x0B | W | 旧版M4低16位兼容入口，自动符号扩展 |
| 0x0C | W | 电磁铁one-hot目标 `[3:0]` |
| 0x0D / 0x2C | W | 旋转舵机角低/高字节 |
| 0x0E / 0x2D | W | 夹爪舵机角低/高字节 |
| 0x2A | W | 电磁铁推出时间，单位10ms |
| 0x2B | W | 电磁铁冷却时间，单位10ms |
| 0x10～0x13 | R | M2/M3位置 |
| 0x18～0x19 | R | M1位置 |
| 0x20～0x21 | R | M4位置 |
| 0x28 | R | 汇总状态/忙标志 |
| 0x30～0x31 | R | 两舵机角低8位（兼容旧界面） |
| 0x32 | R | 电磁铁当前状态 |
| 0x33 | R | 上臂/传送带错误位 |
| 0x40～0x43 | W | M1有符号32位脉冲，按高字节到低字节写入 |
| 0x44～0x47 | W | M2有符号32位脉冲，按高字节到低字节写入 |
| 0x48～0x4B | W | M3有符号32位脉冲，按高字节到低字节写入 |
| 0x4C～0x4F | W | M4有符号32位脉冲，按高字节到低字节写入 |

新龙芯程序应使用 `0x40～0x4F` 的32位寄存器。旧16位入口只用于短距离调试兼容。
