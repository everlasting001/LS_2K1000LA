该项目使用SCARA机械臂
机械臂：
    一个42步进电机负责整个系统的旋转/大臂的角度（减速比 60:16 = 3.75:1）
    一个42步进电机负责大臂和小臂的升降（导程2mm，直驱无减速）
    一个42步进电机负责小臂的角度（减速比 60:16 = 3.75:1）
    一个42步进电机负责传送带
    一个舵机负责夹爪的角度（270度数字舵机，20KG）
    一个舵机负责夹爪的开合（数字舵机, 15KG）
    大臂长度： 25cm
    小臂长度： 15cm
    旋转舵机连杆长度（舵机轴到夹爪工作点）：10cm
    大臂、小臂和旋转舵机连杆均在 XOY 平面旋转，构成平面 3R 机构
传送带: 滚轴直径： 21mm
电机：
    4个42步进电机(张大头光耦+ttl版本)
    2个舵机
    4个推拉式电磁铁

### 旋转舵机 (SERVO1, 270°, 20KG)
- 型号: 270° 数字舵机
- 居中位置: **127°**
- 方向: 角度减小 → **左转**, 角度增大 → **右转**
- 有效范围: 0° ~ 270°
- 127° 对应脉宽: 25000 + (127×100000)/270 = **72037 计数** = **1440.740 μs**

### 夹爪舵机 (SERVO2, 180°, 15KG)
- 型号: 180° 数字舵机
- 最大张开角度: **80°**
- 夹紧物块角度: **140°**
- 有效范围: 0° ~ 180°
- 80° 对应脉宽: 25000 + (80×100000)/180 = **69444 计数** = **1388.880 μs**
- 140° 对应脉宽: 25000 + (140×100000)/180 = **102777 计数** = **2055.540 μs**
