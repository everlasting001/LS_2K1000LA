# ESP32-S3 最终固件（共三份）

> 当前实物说明（2026-08-11）：传送带损坏，比赛现场只要求烧录和使用 `s3_base`、`s3_arm`。`s3_conveyor` 固件保留作为设计记录；该节点缺席应由龙芯界面显示黄色WARN，不阻塞机械臂。

本目录只保留最终方案，三个目录分别对应三块 `ESP32-S3-R8N8`：

| 工程 | MAC | 功能 |
|---|---|---|
| `s3_base` | `44:1B:F6:83:E0:80` | FPGA UART 路由、大臂 M1、汇总状态 |
| `s3_arm` | `44:1B:F6:81:C4:E0` | 升降 M2、小臂 M3、旋转舵机、夹爪舵机 |
| `s3_conveyor` | `44:1B:F6:83:DF:D8` | 传送带 M4、四路推拉电磁铁 |

Arduino IDE 每次只打开对应目录中同名的 `.ino` 文件并选择 ESP32-S3 开发板烧录。

## 接线

### 底盘 S3

- 底盘S3 GPIO1 TX → 大臂M1 RX
- 底盘S3 GPIO2 RX ← 大臂M1 TX
- 底盘S3 GPIO18 RX ← FPGA P19 `router_txd` TX (J14 30)
- 底盘S3 GPIO17 TX → FPGA A15 `router_rxd` RX (J14 29)
- 所有设备必须共地

### 上臂 S3

- 上臂S3 GPIO17 TX → 升降M2 RX
- 上臂S3 GPIO18 RX ← 升降M2 TX
- 上臂S3 GPIO15 TX → 小臂M3 RX
- 上臂S3 GPIO16 RX ← 小臂M3 TX
- GPIO4 → 旋转舵机
- GPIO5 → 夹爪舵机

### 传送带 S3

- 传送带S3 GPIO17 TX → 传送带M4 RX
- 传送带S3 GPIO18 RX ← 传送带M4 TX
- GPIO7 → 电磁铁1驱动输入
- GPIO8 → 电磁铁2驱动输入
- GPIO9 → 电磁铁3驱动输入
- GPIO10 → 电磁铁4驱动输入

电磁铁为高电平推出。GPIO 只能接驱动板逻辑输入，严禁直接驱动电磁铁线圈；驱动板与 S3 需要共地。

## 电磁铁安全策略

- 上电、复位、急停和通信超时均输出 LOW。
- 命令必须为四位 one-hot，同一时刻最多一路推出。
- 默认推出 `200 ms`，最长被固件限制为 `2000 ms`。
- 默认冷却 `500 ms`，冷却期间拒绝再次触发。
- FPGA I2C `0x0C[3:0]` 写 one-hot 目标，`0x2A` 写推出时长（10 ms单位），`0x2B` 写冷却时长（10 ms单位），最后向 `0x00` 写 bit0 触发。
- 急停仍由 `0x00` bit1 触发。

## FPGA UART 帧

FPGA 到底盘 S3 使用固定13字节帧，两个目标值均为有符号32位脉冲数：

```text
AA flags value1[0] value1[1] value1[2] value1[3]
         value2[0] value2[1] value2[2] value2[3]
         speed_lo speed_hi crc8
```

`value1/value2` 为小端 `int32_t`，范围 `-2147483648～2147483647`；`flags`：bit1=M2、bit2=M3、bit3=舵机、bit4=急停、bit5=M1、bit6=M4、bit7=电磁铁。无线段使用带版本号、设备号和CRC-8/0x07的v3协议。

## 无传送带实机协议（当前生效）

- 现场仅烧录 `s3_base` 与 `s3_arm`；`s3_conveyor` 只保留为历史设计记录。
- 底盘 S3 不注册、不轮询传送带节点，也不转发 M4/推杆命令。
- 底盘回 FPGA 状态帧为 18 字节：前 14 字节位置/舵机，byte14=`WARN`，byte15=`ERROR`，byte16=`DONE`，byte17=`CRC-8/0x07`。
- `WARN bit0` 表示传送带缺席，`bit1` 表示四路推杆缺席；它们不阻塞机械臂。
- `DONE bit0/1/2` 分别为 M1/M2/M3，bit3/4 为旋转/夹爪舵机，bit5 为机械臂核心全部到位。

UART 与 ESP-NOW 两段都使用 CRC-8（多项式 `0x07`）。底盘返回 FPGA 的帧为16字节数据加1字节 CRC；校验失败的帧会被丢弃。聚合状态包含 M1～M4 位置、两个16位舵机角、电磁铁状态和通信错误。各执行端约每100 ms读取一次 Emm 位置/状态，ESP-NOW 状态约每50 ms返回；无需龙芯高频轮询。

## 烧录前检查

1. 四个 Emm 均使用出厂默认地址 `1`。每台电机独占一条 UART，不会发生地址冲突，也不需要修改驱动器地址。
2. 电机串口为 `115200 8N1`。
3. 首次只接驱动板逻辑输入，不接电磁铁负载，确认上电 GPIO7～10 均为低电平。
4. 分别触发四路并用万用表确认只有目标 GPIO 变高。
5. 再接线圈电源，线圈电源不要由 ESP32 板供电。
