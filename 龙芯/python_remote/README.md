# 龙芯 SCARA 简易 Python 遥控器

适用于龙芯2K1000LA的 `1024×600` 显示屏，也可在Windows本地以模拟模式运行。

## 功能

- 大臂M1、小臂M3按角度相对运动。
- 升降M2按毫米相对运动。
- 传送带M4按毫米设置相对行程，使用32位脉冲，不需要拆段。
- 设置旋转舵机和夹爪舵机角度。
- 单独触发四路电磁铁并设置推出/冷却时间。
- 全系统急停。
- 将当前机械位置校准为软件零点，并保存至 `zero_points.json`。
- 模拟模式和真实I2C模式可切换。

## 运行

```bash
cd ~/2K1000LA/龙芯/python_remote
python3 scara_remote.py
```

如果Qt没有自动选择显示后端：

```bash
QT_QPA_PLATFORM=wayland python3 scara_remote.py
# 或
QT_QPA_PLATFORM=xcb python3 scara_remote.py
```

真实模式使用 `/dev/i2c-1`、FPGA地址 `0x20`。程序优先导入 `smbus2`，没有时自动尝试系统的 `smbus`。

## 第一次上板

1. 保持模拟模式，检查所有按钮和数值换算。
2. 给机构手动复位到机械零点，进入“零点校准与状态”，点击“全部设为机械零点”。
3. 切换真实I2C模式并连接。
4. 电机先使用低速、小步长测试，逐一确认正负方向。
5. 电磁铁先不接线圈负载，测量GPIO7～10，确认上电全低且每次只有一路变高。

注意：当前零点校准是龙芯端的软件零点记录，不会修改Emm驱动器内部零点，也不会自动驱动机械臂回零。
